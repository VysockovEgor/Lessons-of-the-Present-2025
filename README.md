# Уроки Настоящего

В этом репозитории представлен **Jupyter Notebook** с решениями трёх задач проекта «Сириус: Уроки Настоящего»: коррекция микроскопических кадров, сборка кадров из строк с пропусками и анализ данных бортовых датчиков космического аппарата «Нанозонд‑1».

## Структура проекта

```
.
├── 65-161day-04dec2023.txt       # Сырые данные телеметрии за 65–161 день 2023 года
├── data.json                     # Данные показателей спутника и показатели солнечных вспышек
├── dncnn_15.pth                  # Предобученные веса модели DnCNN для фильтрации шума
├── Norm.bmp                      # Пример «чистого» кадра микроскопа
├── Norm.txt                      # Пример «чистого» кадра микроскопа в байтах
├── Temp.bmp                      # Искажённый кадр для задачи коррекции
├── README.md                     # Этот файл — описание проекта и инструкции
└── Уроки_Настоящего.ipynb        # Основной Jupyter Notebook с реализациями и выводами
```

## Установка и запуск

1. **Создайте и активируйте виртуальное окружение**:
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   ```
2. **Установите зависимости**:
   ```bash
   pip install -r requirements.txt
   ```
3. **Запустите Jupyter Notebook**:
   ```bash
   jupyter notebook Уроки_Настоящего.ipynb
   ```

## Описание содержимого

- **Часть 1: Коррекция микроскопических кадров**
  - Загрузка «Norm.bmp» и «Temp.bmp»
  - Применение комбинации предобученной DnCNN (dncnn_15.pth) и метода резинового листа

- **Часть 2: Восстановление фотографии медианным фильтром**
  - Импорт строк кадра из текстовых/графических файлов
  - Оценка точности по MSE и PSNR

- **Часть 3: Анализ данных «Нанозонд‑1»**
  - Загрузка телеметрии из `65-161day-04dec2023.txt` и `data.json`
  - Визуализация временных рядов датчиков
  - Сопоставление пиков с событиями в космосе (солнечные вспышки, геомагнитные бури)

## Файлы и их назначение

- `65-161day-04dec2023.txt` — сырые телеметрические данные за 65–161 день 2023 года
- `data.json` — предварительно обработанные данные для удобного анализа
- `dncnn_15.pth` — веса DnCNN для удаления шумов с микроскопических кадров
- `kaggle.json` — файл с API‑токеном для доступа к данным Kaggle (опционально)
- `Norm.bmp`, `Temp.bmp` — примеры исходного и искажённого изображений для коррекции
- `Norm.txt` — метаданные (размер, формат и т.д.) к файлу `Norm.bmp`
- `Уроки_Настоящего.ipynb` — основной ноутбук с полным решением
